\# pc-bootstrap



Windows PC を「壊れてもすぐ戻せる」状態で

初期セットアップするための bootstrap / dotfiles リポジトリ。



\## 目的

\- 寄贈ノートPCの再現可能なセットアップ

\- 開発兼雑用PCの横展開

\- 手動作業と判断の文書化



\## フォルダ構成

\- docs/        : 設計・判断理由

\- bootstrap/   : 初回実行エントリ

\- install/     : winget インストール

\- terminal/    : Windows Terminal 設定

\- git/         : Git 設定

\- powershell/  : PowerShell 設定

\- keyboard/    : キーボード配列制御



\## 進め方

\- まずローカルで構築

\- 動いたものだけを段階的に管理対象にする
