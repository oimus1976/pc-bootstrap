# pc-bootstrap

Windows PC を「壊れてもすぐ戻せる」状態で
初期セットアップするための bootstrap / dotfiles リポジトリ。

## 目的

- 寄贈ノートPCの再現可能なセットアップ
- 開発兼雑用PCの横展開
- 手動作業と判断の文書化

## 現在の構成

- `docs/`: 設計・判断理由、セットアップ手順
- `vscode/`: VS Code 関連の管理対象

READMEに記載していない構成は、実装・検証できたものから段階的に追加する。

## 進め方

- まずローカルで構築する
- 動いたものだけを段階的に管理対象にする
- 秘密鍵、トークン、資格情報、未確認のユーザー固有設定はGit管理しない
